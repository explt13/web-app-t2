# API «Видно горы?»

Базовый адрес: `http://localhost:8080` (порт задаётся `APP_PORT` в `.env`).

Все ответы в JSON. Тело запросов тоже JSON, с заголовком `Content-Type: application/json`.

## Сводка эндпоинтов

| Метод | Путь | Описание | Успешный ответ |
|---|---|---|---|
| GET | `/` | информация о сервисе | 200 |
| GET | `/health` | проверка связи с базой | 200 |
| GET | `/districts` | список районов Алматы | 200 |
| GET | `/reports` | список наблюдений | 200 |
| GET | `/reports/:id` | одно наблюдение по id | 200 |
| POST | `/reports` | создать наблюдение | 201 |
| PUT | `/reports/:id` | изменить наблюдение | 200 |
| DELETE | `/reports/:id` | удалить наблюдение | 204 |
| GET | `/today` | сводка видимости гор за сегодня | 200 |

## Наблюдение (report)

| Поле | Тип | Описание |
|---|---|---|
| `id` | number | присваивается базой |
| `district` | string | slug района: `alatau`, `almaly`, `auezov`, `bostandyk`, `zhetysu`, `medeu`, `nauryzbay`, `turksib` |
| `district_name` | string | название района, только в ответах |
| `visibility` | string | `yes` — горы видно, `partly` — дымка, `no` — не видно |
| `comment` | string \| null | необязательный, до 280 символов |
| `created_at` | string | время создания, ISO 8601 в UTC |

Пример:

```json
{
  "id": 1,
  "district": "bostandyk",
  "district_name": "Бостандыкский",
  "visibility": "yes",
  "comment": "Пик Фурманова как на ладони",
  "created_at": "2026-10-17T08:46:53.472Z"
}
```

## Ошибки

При ошибке приходит объект с полем `error`:

```json
{ "error": "наблюдение 999 не найдено" }
```

| Код | Когда |
|---|---|
| 400 | неверное тело запроса, неизвестный район, некорректный id, сломанный JSON |
| 404 | наблюдение с таким id не найдено или нет такого эндпоинта |
| 500 | ошибка на сервере (например, база недоступна) |

---

## GET /health

Делает `SELECT 1` в базе. Если база недоступна, вернёт 500.

```json
{ "status": "ok" }
```

## GET /districts

```json
[
  { "slug": "alatau", "name": "Алатауский" },
  { "slug": "almaly", "name": "Алмалинский" }
]
```

## GET /reports

Последние наблюдения, сначала новые.

| Query-параметр | По умолчанию | Описание |
|---|---|---|
| `district` | все районы | slug района |
| `limit` | 20 | от 1 до 100 |

Пример: `GET /reports?district=turksib&limit=5`

Ответ: массив наблюдений.

## GET /reports/:id

Ответ: одно наблюдение. 404, если такого id нет, 400, если id не число.

## POST /reports

Тело:

```json
{
  "district": "turksib",
  "visibility": "no",
  "comment": "Смог, даже соседний дом в дымке"
}
```

`district` и `visibility` обязательны, `comment` можно не передавать.

Ответ `201 Created`: созданное наблюдение с `id`.

## PUT /reports/:id

Полностью заменяет редактируемые поля наблюдения. Тело такое же, как у POST: `district` и `visibility` обязательны. Если `comment` не передать, он станет `null`.

```json
{
  "district": "turksib",
  "visibility": "partly",
  "comment": "К обеду ветер разогнал смог"
}
```

Ответ `200 OK`: обновлённое наблюдение. 404, если такого id нет.

## DELETE /reports/:id

Ответ `204 No Content` без тела. 404, если такого id нет.

## GET /today

Сводка за текущие сутки по времени Алматы. `score` — процент видимости, где «видно» = 1, «дымка» = 0.5, «не видно» = 0. Если в районе нет наблюдений, `score` равен `null`.

```json
{
  "city": { "reports": 3, "score": 50, "verdict": "дымка, горы еле угадываются" },
  "districts": [
    {
      "district": "turksib",
      "name": "Турксибский",
      "reports": 2,
      "votes": { "yes": 0, "partly": 1, "no": 1 },
      "score": 25,
      "verdict": "гор не видно, лучше закрыть окна"
    }
  ]
}
```

Вердикт: 70 и выше — горы видно, от 35 до 69 — дымка, ниже 35 — не видно.
